# Popover

Extra information or small controls anchored to a trigger. The popup is a
surface at elevation 2, positioned next to its trigger; the page behind stays
usable.

<Popover.Root>
  <Popover.Trigger>Notifications</Popover.Trigger>
  <Popover.Portal>
    <Popover.Positioner sideOffset={8}>
      <Popover.Popup>
        <Popover.Title>Notifications</Popover.Title>
        <Popover.Description>You are all caught up.</Popover.Description>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>

## Usage

Use Popover for secondary content: definitions, small forms, help text. Do not
use it for a list of commands — use Menu. Do not use it when the user must read
or act before continuing — use Dialog.

## Base UI API

Wraps Base UI's `Popover`; every part passes through unchanged, styled via
`part()`. `modal` keeps Base UI's non-modal default.

| Element | Notes |
| ------- | ----- |
| `Root` props (`open`, `defaultOpen`, `onOpenChange`, `modal`, `delay`, `closeDelay`, ...) | Exposed — full passthrough. |
| `Trigger`, `Close` | Styled as Action buttons; Close pins `data-priority: 'tertiary'`. |
| `Portal`, `Positioner`, `Backdrop` | Portal passthrough; backdrop gets the Overlay scrim. |
| `Popup` | Surface elevation 2, popup transitions. |
| `Title`, `Description` | Label type / body color. |
| `openOnHover` / `delay` / `closeDelay` (Trigger) | Exposed — passthrough, not documented (edge-case hover behavior). |
| `data-open`, `data-starting-style`, `data-ending-style` | Consumed by CSS for popup/backdrop transitions. |
| Callback-form `className`/`style` | Available via passthrough, not documented. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `modal` | `boolean \| 'trap-focus'` | `false` | Non-modal by default: the page behind stays usable. Set `true` to block outside interaction. |
| `side` / `align` / `sideOffset` (Positioner) | — | — | Placement relative to the trigger and the gap from it. |
| `children` | `ReactNode` | — | Part content: positioner, popup, title, description. |

`open`/`defaultOpen`, `onOpenChange`, `data-priority`, `render`, and standard attributes are passthrough — they appear here only, never get their own section.

## Open state

The trigger opens the popover; the popup anchors to it. Escape, outside
press, or a `Close` part dismisses.

<Popover.Root>
  <Popover.Trigger>Notifications</Popover.Trigger>
  <Popover.Portal>
    <Popover.Positioner sideOffset={8}>
      <Popover.Popup>
        <Popover.Title>Notifications</Popover.Title>
        <Popover.Description>You are all caught up.</Popover.Description>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>

## Non-modal

A popover never blocks the page by default: click outside, and it dismisses
while the page keeps working. This is the difference from Dialog.

<Popover.Root>
  <Popover.Trigger data-priority="tertiary">What's this?</Popover.Trigger>
  <Popover.Portal>
    <Popover.Positioner sideOffset={4}>
      <Popover.Popup>Billing happens on the 1st of each month.</Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| Popup ground | `hds/sem/surface/color/2/default/{bg,border,shadow}`, `hds/sem/surface/measure/*` |
| Backdrop (when rendered) | `hds/sem/overlay/color/bg` |
| Trigger | `hds/sem/action/color/secondary/*`, `hds/sem/action/measure/md/*` |
| Close | `hds/sem/action/color/tertiary/*` |
| Title | `hds/sem/type/color/label/fg`, `hds/sem/type/measure/label/*`, `hds/sem/type/other/label/*` |
| Description | `hds/sem/type/color/body/fg` |
| Focus ring | `hds/sem/focus/color/stroke`, `hds/sem/focus/measure/stroke-width` |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/popover`; the namespace is mirrored
  and every prop passes through. `Trigger`, `Backdrop`, `Positioner`, `Popup`,
  `Title`, `Description`, and `Close` are the styled parts.
- Extension decisions: no extension props. Elevation fixed at 2; popup
  max-width structural (`min(24rem, var(--available-width))`). `Close` pins
  tertiary; the trigger keeps the secondary button look, changeable with
  `data-priority` (same decisions-vs-code flag as Dialog).
- Known constraints: hover-open (`openOnHover`, `delay`, `closeDelay`) works
  through passthrough but is undocumented; document it if a surface needs it.
- Accessibility: the popup is labeled by `Title` and announced on open. Escape
  closes; focus returns to the trigger.
