import { useState } from 'react';
import { Button, Checkbox, Field, Inline, Popover, Stack } from 'handy-ds';

export function FilterDemo() {
  const [open, setOpen] = useState(false);
  return (
    <Popover
      open={open}
      onOpenChange={setOpen}
      title="Filter results"
      align="start"
      width="8000"
      content={
        <Stack gap="400">
          <Field.Root><Field.Label><Checkbox name="stock" />In stock</Field.Label></Field.Root>
          <Button onClick={() => setOpen(false)}>Apply</Button>
        </Stack>
      }
    >
      <Button variant="secondary">Filters</Button>
    </Popover>
  );
}

# Popover

Popover is a small panel next to a control. A click on the control opens it. The page
behind stays usable. Popover is one component: it wraps its control, `title` is the
heading, and `content` is the panel body. A click outside, `Escape`, or the X button
closes it.

<Popover title="Annual percentage rate" content="The yearly cost of the loan, with interest and fees.">
  <Button variant="tertiary">What is APR?</Button>
</Popover>

## Usage

Use Popover for short, secondary content: a definition, help text, or a small form such as a
filter. Wrap exactly one control, such as a Button. No state code is necessary.

Do not use Popover for a list of commands. Use Menu. Do not use it for a task the user must
finish before going on. Use Dialog. Do not use it for a label that shows on hover. Use
Tooltip.

## Base UI API

Popover wraps `@base-ui/react/popover`. The parts are internal. None is exported.

| Element | Notes |
| ------- | ----- |
| `Root` `open`, `onOpenChange` | Exposed, optional. Use them only to close the panel from code. |
| `Root` `defaultOpen`, `modal`, `onOpenChangeComplete`, `actionsRef`, `handle`, trigger IDs | Omitted. `modal` is fixed `false`. |
| `Trigger` | Renders the child through `render`. No class and no look. Hover open and delays are omitted. |
| `Portal`, `Positioner` | Rendered inside. `side` and `align` are exposed. The side gap is fixed at `measure/space/200`. |
| Other `Positioner` members, `Arrow`, `Backdrop`, `Viewport`, `Description` | Omitted. |
| `Popup` `initialFocus`, `finalFocus` | Omitted. Base UI default focus. |
| `Title` | Rendered from `title`. |
| `Close` | The X button only. |
| `render`, `className`, `style` | Omitted. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactElement` | required | The control that opens the panel. One element. |
| `title` | `ReactNode` | required | The heading of the panel, next to the X. Screen readers read it as the panel name. |
| `content` | `ReactNode` | required | The panel body. |
| `side` | `'top' \| 'bottom' \| 'inline-start' \| 'inline-end'` | `'bottom'` | The side of the control the panel opens on. The panel flips when it does not fit. |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | How the panel lines up along the control. |
| `width` | `'auto' \| '6400' \| '8000' \| '9600' \| '12800'` | `'auto'` | Width of the panel. `auto`: the content sets it, up to `maxWidth`. |
| `maxWidth` | `'6400' \| '8000' \| '9600' \| '12800'` | `'9600'` | Largest width of the panel. It wins over a larger `width`. |
| `open` | `boolean` | — | Optional. Use with `onOpenChange` only to close the panel from code. |
| `onOpenChange` | `(open: boolean) => void` | — | Optional. Called when the panel opens or closes. |

## Side

`side` sets the side of the control that the panel opens on. `inline-start` and `inline-end`
follow the text direction. The panel flips when it does not fit.

  <Popover side="top" title="Top" content="The panel opens above."><Button variant="secondary">top</Button></Popover>
  <Popover side="bottom" title="Bottom" content="The panel opens below."><Button variant="secondary">bottom</Button></Popover>
  <Popover side="inline-start" title="Inline start" content="The panel opens at the start side."><Button variant="secondary">inline-start</Button></Popover>
  <Popover side="inline-end" title="Inline end" content="The panel opens at the end side."><Button variant="secondary">inline-end</Button></Popover>
</Inline>

## Align

`align` sets how the panel lines up along the control. `start` aligns the start edges.
`center` centers the panel. `end` aligns the end edges.

<Inline gap="200">
  <Popover align="start" width="8000" title="Start" content="The start edges line up."><Button variant="secondary">start</Button></Popover>
  <Popover align="center" width="8000" title="Center" content="The panel is centered."><Button variant="secondary">center</Button></Popover>
  <Popover align="end" width="8000" title="End" content="The end edges line up."><Button variant="secondary">end</Button></Popover>
</Inline>

## Width

`width` sets the width of the panel. `auto` lets the content set it, up to `maxWidth`. The
steps read `measure/width/{step}`. The panel shrinks to the space on the screen.

<Inline gap="200">
  <Popover width="auto" title="Auto" content="Short text."><Button variant="secondary">auto</Button></Popover>
  <Popover width="6400" title="6400" content="A narrow panel."><Button variant="secondary">6400</Button></Popover>
  <Popover width="8000" title="8000" content="A medium panel."><Button variant="secondary">8000</Button></Popover>
  <Popover width="9600" title="9600" content="A wide panel."><Button variant="secondary">9600</Button></Popover>
  <Popover width="12800" maxWidth="12800" title="12800" content="An extra wide panel. Set maxWidth too, because the default maxWidth is 9600."><Button variant="secondary">12800</Button></Popover>
</Inline>

## Max width

`maxWidth` sets the largest width of the panel. It wins over a larger `width`. Each example
has long content and `width="auto"`.

## Owner notes

- Base UI mapping: `Root`, `Trigger`, `Portal`, `Positioner`, `Popup`, `Title`, and `Close`
  from `@base-ui/react/popover`, all inside `<Popover>`.
- Extension decisions: one component with `title` and `content` props (overlay exception in
  `docs/api-conventions.md` section 1). The child is the trigger. `modal` is fixed `false`.
  The X is a tertiary Button, size `800`.
- Known constraints: the panel renders at the end of the page. It uses the page colors and
  mode. A `data-context`, `data-mode`, or `data-section` on an ancestor does not reach it.
- Accessibility: the title names the panel. `Escape` closes it. Focus goes back to the
  control on close.
