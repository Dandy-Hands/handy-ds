# Drivers

The only client input. Values here are the live docs theme: change them in the **Theme ⚙**
flyout and this page follows. The full driver list with defaults is in the token spec, section 3.

- **Palette drivers** (`color.*`, `typography.family`, `density`, ...) shape the primitives.
- **Pick drivers** (`picks.*`, `contexts.*`, `roles.*`, `radius.*`, `border.*`, `typography.styles`)
  choose which primitive each semantic token reads. Each has a default; only overrides show here.
