# Sem tokens

`hds/sem/{category}/{type}/[axis]/[state]/{property}` — the application layer,
named by purpose. These are the tokens components read, emitted at `:root`.

- **Reads** names the ref token each value comes from — the ref→sym mapping itself.
- **Literal** rows are hand-set values in the Theme Map (`transparent`, `color-mix(…)`).
- Values are the live docs theme; use the **Theme ⚙** flyout to see them move.
