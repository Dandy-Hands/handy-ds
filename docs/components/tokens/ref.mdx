# Ref tokens

`hds/prim/*` — the palettes. Frozen shape, values derived from the drivers.
The shape of every group below is fixed; only the values change with the theme.

Components never read these directly. Semantic tokens point at them (see the
**Sem** pages, where each token's **Reads** column names its ref).
