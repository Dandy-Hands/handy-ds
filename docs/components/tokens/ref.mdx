# Ref tokens

`hds/prim/*`: the primitives. Frozen shape, values derived from the drivers. Color has
11 hue slots of 11 stops, a neutral scale, white, black, and role aliases. The dark palette
uses the same names with an inverted lightness ladder.

Components never read these directly. Semantic tokens point at them.
