# PasswordInput

A single-line field for a password. It starts hidden. A button inside the field shows or
hides the text. Strength and rules are not part of the component. The caller reads the
value and shows the result in its own markup.

<div style={col}>
  <Field.Root>
    <Field.Label>Password</Field.Label>
    <PasswordInput defaultValue="correct horse" />
  </Field.Root>
</div>

## Usage

Use PasswordInput when the user enters or confirms a password. Wrap it in a `Field` when
it has a visible label. For a bare PasswordInput, give it an `aria-label`. Pass
`autoComplete="new-password"` on a sign-up or change-password form. Do not use it for a
value that is not secret. Use TextInput instead.

## Base UI API

Built on the shared input base, which wraps Base UI's `Input`. The base is internal.

| Element | Notes |
| ------- | ----- |
| `value`, `defaultValue`, `onValueChange` | Exposed on the input. |
| Native input attributes (`name`, `placeholder`, `disabled`, `required`, `readOnly`, `inputMode`, `maxLength`, `id`, `aria-*`) | Exposed on the input. |
| `autoComplete`, `autoCapitalize`, `spellCheck` | Exposed as native attributes. Defaults: `current-password`, `off`, `false`. |
| `ref`, `render` | Exposed on the input. |
| `className` | Exposed on the frame. |
| `type`, `end`, `size` (the HTML attribute), `style` | Removed. The toggle state sets `type`. The button owns `end`. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `'800' \| '1000' \| '1200'` | `'1000'` | Height of the field. `800`: compact, for dense layouts. `1000`: standard. `1200`: large, for touch layouts. |
| `start` | `ReactNode` | — | Content before the text, such as a lock icon. |
| `value` / `defaultValue` | `string` | `''` | The controlled / initial text. |
| `onValueChange` | `(value: string, eventDetails) => void` | — | Called when the text changes. |
| `autoComplete` | `string` | `'current-password'` | Tells the browser which password to offer. Use `'new-password'` for a new password. |
| `placeholder` | `string` | — | Hint text shown when the field is empty. |
| `disabled` | `boolean` | `false` | Makes the field and its button visible but inert. |
| `readOnly` | `boolean` | `false` | Shows the text but blocks changes. The button still works. |
| `required` | `boolean` | `false` | The field must have text before the form submits. |
| `name` | `string` | — | Identifies the field on form submission. |
| `className` | `string` | — | Class for the outer frame. |
| `render` | `ReactElement \| (props, state) => ReactElement` | — | Replaces the rendered input element. |

Event handlers, form props, and `render` appear here only. They have no section below.

## Size

The size axis. Each step is a `measure/size` token and sets the height.

<div style={col}>
  <PasswordInput size="800" aria-label="Size 800" placeholder="800" />
  <PasswordInput size="1000" aria-label="Size 1000" placeholder="1000" />
  <PasswordInput size="1200" aria-label="Size 1200" placeholder="1200" />
</div>

## Show and hide

The field starts hidden. The button switches between `type="password"` and `type="text"`.
The icon shows the action: an open eye while hidden, a crossed eye while shown. The
button label is `Show password`. It does not change. `aria-pressed` reports the state.

<div style={col}>
  <PasswordInput aria-label="Password" defaultValue="correct horse" />
</div>

## Start

`start` takes any node, such as an icon.

<div style={col}>
  <PasswordInput aria-label="Password with icon" start={<Icon>lock</Icon>} placeholder="Password" />
</div>

## Disabled

A disabled field disables its button too.

<div style={col}>
  <PasswordInput aria-label="Disabled" placeholder="Disabled" disabled />
</div>

## Owner notes

- Base UI mapping: built on the shared input base, which wraps `@base-ui/react/input` 1.8.0.
- Extension decisions: no new props. Toggle state is internal, and the field starts hidden.
  The state props `visible`, `defaultVisible`, and `onVisibleChange` can be added later.
  The label `Show password` is a fixed English string. A label prop can be added when a
  client needs another language.
- Known constraints: the icons need the Material Symbols font, and the client loads it.
  There is no strength hint. Read the value with `onValueChange` and show the result
  in your own markup. The field does not hide the text again on blur or on submit.
- Accessibility: the button is a native button in the tab order with `aria-pressed`. A
  pointer press keeps focus in the input. In `Field.Root`, the label, description, and
  error are wired to the input.
