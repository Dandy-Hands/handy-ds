# Separator

A dividing line between groups that spacing alone does not separate. Reads the
Divider category: one color, three thicknesses.

<Separator />
<Separator weight="medium" />

## Usage

Use Separator between groups of content, and inside toolbars and menus. Do not
use it when spacing is enough — a line is noise. Keep weights consistent within
one surface.

## Base UI API

Wraps Base UI's `Separator`; full passthrough.

| Element | Notes |
| ------- | ----- |
| Props (`orientation`, `role` presentation defaults, native `div` props, ...) | Exposed — full passthrough. |
| `orientation` | Base UI's prop, consumed by the CSS (`data-orientation='vertical'`). |
| `render` | Exposed — passthrough. |
| Callback-form `className`/`style` | Available via passthrough, not documented. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `weight` | `'thin' \| 'medium' \| 'thick'` | `'thin'` | Line thickness. `thin` — default hairline. `medium` — heavier, e.g. under a table header. `thick` — strongest emphasis. |
| `children` | `ReactNode` | — | Content inside the divider, if any. |

`render`, `orientation`, and standard attributes are passthrough — they appear here only, never get their own section (`orientation` is covered under its own axis section).

## Owner notes

- Base UI mapping: wraps `@base-ui/react/separator`; every prop passes through,
  including `orientation` and `render`.
- Extension decisions: `weight` (default `thin`) is the only wrapper prop; it
  sets `data-weight`. Vertical orientation is structural — no extra tokens.
- Known constraints: none. The line is context-passive; on-primary grounds
  automatically get the overridden divider color.
- Accessibility: renders with the separator role and correct semantics through
  the underlying behavior; decorative use is hidden from assistive tech by
  default.
