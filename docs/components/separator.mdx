# Separator

A line that marks a boundary between two groups of content. It reads the Graphic
category: one width, two tones. Screen readers announce it as a separator, like
an HTML `<hr>`.

<div style={{ display: 'grid', gap: 12 }}>
  <Text variant="headline" render={<h3 />}>Billing</Text>
  <Separator />
  <Text>Invoiced monthly.</Text>
</div>

## Usage

Use Separator where spacing alone does not show that one group stops and the
next starts. Do not use it for decoration: screen readers announce every
Separator. Use spacing, or a border on the container, instead. Use
`tone="strong"` only where a boundary needs more contrast than the default line.

## Base UI API

Wraps Base UI's `Separator`. Only `orientation` passes through.

| Element | Notes |
| ------- | ----- |
| `orientation` | Exposed. Sets `aria-orientation` and `data-orientation`. |
| `role="separator"` | Always set. No prop changes it. |
| `render`, `className`, `style`, `ref`, native `div` props | Removed. Separator accepts no other props; the parent layout `gap` sets the space around it. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Line direction. `horizontal`: a line across the width, between stacked groups. `vertical`: an upright line that fills the row height, between groups in a row. |
| `tone` | `'default' \| 'strong'` | `'default'` | Line color. `default`: the standard divider. `strong`: more contrast, for a boundary that must stand out. |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/separator`. Only `orientation` passes through.
- Extension decisions: `tone` (default `default`) replaces the old `weight` axis. The old
  `medium` and `thick` steps read space tokens as line widths. The removal of `render` and
  `className` is a recorded break of the escape-hatch rule: Separator stays minimal.
- Known constraints: one line width only, set by the `border.divider` driver. The Separator
  parts of Menu, Select, Combobox, and Toolbar share this CSS at tone `default`. The line
  color follows `data-context` and `data-section` overrides.
- Accessibility: always `role="separator"` with `aria-orientation`. It is not focusable.
