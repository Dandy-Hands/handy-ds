# Aside

A column of supporting content beside the main content of a page: a side nav,
an outline, sources, or related links. It has a width, an optional background,
and optional sticky behavior. Renders an `aside` element.

<div style={{ display: 'flex', alignItems: 'flex-start' }}>
  <div style={{ flex: 1, padding: '1rem' }}><Text>Main content.</Text></div>
  <Aside surface="sunken" aria-label="On this page">
    <nav aria-label="Table of contents">
      <Stack gap="200" render={<ul style={{ listStyle: 'none', margin: 0, padding: 0 }} />}>
        <li>Overview</li>
        <li>Details</li>
        <li>Sources</li>
      </Stack>
    </nav>
  </Aside>
</div>

## Usage

Use Aside for a side nav, an outline, a list of sources, or related links.
Put a `<nav>` element inside an Aside that holds navigation. Do not use it to
place itself beside the main content (use Grid). Do not use it for a drawer that
opens and closes. A page with more than one aside needs an `aria-label` on each.

## Base UI API

No Base UI primitive — a single-part `useRender` component.

| Element | Notes |
| ------- | ----- |
| `render` | Exposed — swap the element without changing the layout. |
| Native `aside` props (`id`, `aria-*`, `className`, ...) | Exposed — full passthrough. `style` is not part of the type. `aria-label` names the landmark. There is no `label` prop. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `width` | `"6400" \| "8000" \| "9600" \| "12800" \| "full"`, or `{ base, sm, md, lg, xl }` of these | `"8000"` | Width of the column. A larger value is a wider column. `"full"` — the width of the parent. |
| `sticky` | `boolean` | `false` | The column stays in view while the page scrolls. It scrolls inside itself when it is taller than the screen. |
| `surface` | `"sunken" \| "base" \| "raised" \| "primary" \| "secondary"` | — | Background color. Absent — no background. `primary`, `secondary` — the brand color; text and controls inside switch to their on-brand colors. |
| `paddingBlock` | `"none"`, a space step, or `{ base, sm, md, lg, xl }` of these | `"400"` | Space above and below the content. |
| `paddingInline` | `"none"`, a space step, or `{ base, sm, md, lg, xl }` of these | `"400"` | Space at the left and right edges. |
| `children` | `ReactNode` | — | The content. |

### Responsive width

Pass an object to change the width from a screen width up. `base` is required.
Keys apply from 640 (`sm`), 768 (`md`), 1024 (`lg`), and 1280 (`xl`) pixels.
Resize the window to see the width change at 768 pixels.

## Sticky

With `sticky` the column stays at the top of the screen while the page scrolls.
When it is taller than the screen, it scrolls inside itself.

<div style={{ display: 'flex', alignItems: 'flex-start' }}>
  <div style={{ flex: 1 }}>
    <Text>Scroll the page. The column on the right stays in view.</Text>
    <div style={{ height: '60rem' }} />
  </div>
  <Aside sticky surface="sunken" aria-label="Sticky example"><Text>Sticky column.</Text></Aside>
</div>

## Padding

`paddingBlock` and `paddingInline` set the space inside the column. Both take
`"none"` or a space step, and both accept the responsive object form.

## Owner notes

- Base UI mapping: no Base UI primitive — a `useRender` component with the
  same `render` semantics as Base UI parts.
- Extension decisions: `surface="primary"` and `"secondary"` set
  `data-context="on-primary"` or `"on-secondary"`. The responsive values go to
  private custom properties (`--_width-base` to `--_width-xl`, and the same for
  padding). Axes show as `data-width`, `data-surface`, and `data-sticky`.
- Known constraints: a sticky Aside sticks at `top: 0`, so it slides under a
  sticky Header. The `overflow-y: auto` rule applies only with `sticky`.
- Accessibility: the element is a landmark. Name each one with `aria-label`
  when a page has more than one.
