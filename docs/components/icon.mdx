# Icon

Wraps an SVG so it takes an icon role color and a size. The SVG must use
`currentColor` for its stroke or fill; the box defaults to the surrounding font
size.

<Icon tone="accent" label="Star">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2"><path d="M12 2l3 7 7 .6-5.3 4.7 1.6 7L12 17.8 5.7 21.3l1.6-7L2 9.6 9 9z" /></svg>
</Icon>

## Usage

Use Icon for any icon; the SVG draws with `currentColor`. Do not use it for
content images — use `<img>`. Omit `tone` inside a Button or Alert so the
icon matches the text around it. Give `label` to an icon that carries meaning
on its own.

## Base UI API

No Base UI primitive — a plain function component over native `span` props.

| Element | Notes |
| ------- | ----- |
| Native `span` props (`id`, `className`, `style`, ...) | Exposed — full passthrough. |
| `aria-*` handling | Managed by the component from `label`: `role="img"` + `aria-label` when labeled, `aria-hidden` otherwise. |
| Callback-form `className`/`style` | Available via passthrough, not documented. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `tone` | `'strong' \| 'default' \| 'muted' \| 'accent' \| 'danger' \| 'warning' \| 'success' \| 'info'` | inherits the surrounding text color | Icon color from Content or Feedback tokens. |
| `fill` | `boolean` | `false` | Filled glyph. Glyph names only. |
| `size` | `'400' \| ... \| '3200'` | the surrounding font size | A measure size step. |
| `label` | `string` | none — the icon is hidden from assistive tech | Accessible name for an icon that carries meaning on its own. |
| `children` | `ReactElement \| string` | — | An SVG using `currentColor`, or a glyph name. |

Standard attributes are passthrough — they appear here only, never get their own section.

## Tone

The role picks the Icon color token. Without a tone the icon keeps
`currentColor` and matches its surroundings — the right choice inside buttons
and alerts.

## Size

`size` takes a size step and sets the box. The default is the surrounding
font size.

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| `tone="default"` | `hds/sem/color/content/default/fg` |
| `tone="muted"` | `hds/sem/color/content/muted/fg` |
| `tone="accent"` | `hds/sem/color/content/accent/fg` |
| Unset tone | inherits `currentColor` — no token read |
| Size | `hds/sem/measure/size/{step}` (unset: `1em`) |

## Owner notes

- Base UI mapping: no Base UI primitive — a plain span wrapper. There is no
  icon component to wrap; the icon artwork always comes from the caller.
- Extension decisions: `tone`, `size`, and `label` are the whole surface.
  Size deliberately has no measure token (spec section 7); it rides a private
  custom property and defaults to the text size.
- Known constraints: the SVG must draw with `currentColor` — a hard-coded
  `stroke` or `fill` ignores the theme.
- Accessibility: `label` makes the icon an image with a name; without it the
  icon is decorative and hidden from assistive tech. Never rely on an unlabeled
  icon as the only control affordance.
