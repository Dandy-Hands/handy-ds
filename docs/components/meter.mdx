# Meter

A static measurement inside a known range, such as storage used or a score. It has
a label, a track, a fill, and an optional formatted value. Screen readers announce
it as a meter with its value.

<Meter.Root value={72}><Meter.Label>Storage</Meter.Label><Meter.Value /><Meter.Track><Meter.Indicator /></Meter.Track></Meter.Root>

## Usage

Use Meter when the number means something on its own and has a known range. Do not
use it for a running task: use Progress. Set `tone` to show status, for example
`warning` near a limit and `danger` over it. The caller picks the tone; Meter does
not compute it from the value.

## Base UI API

Wraps Base UI's `Meter`. Each part takes only the props listed below.

| Element | Notes |
| ------- | ----- |
| `Root`: `value`, `min`, `max`, `format`, `locale`, `aria-valuetext`, `getAriaValueText` | Exposed. |
| `Value` children as a function | Exposed. Returns the text to show. |
| `Label`, `Track` children | Exposed. |
| `Indicator` | Exposed, no props. |
| `render`, `className`, `style`, `ref`, native props on every part | Removed. The parent layout `gap` sets the space around a Meter. |

## Extension API

### Meter.Root

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | — | Required. The current value. |
| `min` | `number` | `0` | The low end of the range. |
| `max` | `number` | `100` | The high end of the range. |
| `tone` | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` | Fill color. `info`: a neutral reading. `success`: a good level. `warning`: near a limit. `danger`: over a limit. |
| `size` | `'200' \| '300' \| '400'` | `'300'` | Track height. `200`: a thin bar. `300`: the standard bar. `400`: a thick bar. Text size does not change. |
| `format` | `Intl.NumberFormatOptions` | percent | Formats the number that `Meter.Value` shows and screen readers announce. |
| `locale` | `Intl.LocalesArgument` | the user's locale | The locale for `format`. |
| `aria-valuetext` | `string` | — | Text that screen readers announce in place of the number. |
| `getAriaValueText` | `(formattedValue, value) => string` | — | Returns the text that screen readers announce. |
| `children` | `ReactNode` | — | The parts: `Label`, `Value`, and `Track` with `Indicator` inside. |

### Meter.Label

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | — | The visible name of the meter. Always include it. |

### Meter.Value

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `(formattedValue, value) => ReactNode` | — | Optional. Returns the text to show. Without it, Value shows the formatted number. |

### Meter.Track

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | — | Holds `Meter.Indicator`. |

### Meter.Indicator

Meter.Indicator takes no props.

## Tone

The tone picks the fill color from the Feedback category. The track color stays
the same.

### tone="info"

<Meter.Root value={40} tone="info"><Meter.Label>Storage</Meter.Label><Meter.Value /><Meter.Track><Meter.Indicator /></Meter.Track></Meter.Root>

### tone="success"

<Meter.Root value={100} tone="success"><Meter.Label>Profile complete</Meter.Label><Meter.Value /><Meter.Track><Meter.Indicator /></Meter.Track></Meter.Root>

### tone="warning"

<Meter.Root value={81} tone="warning"><Meter.Label>API quota</Meter.Label><Meter.Value /><Meter.Track><Meter.Indicator /></Meter.Track></Meter.Root>

### tone="danger"

<Meter.Root value={94} tone="danger" format={{ style: 'decimal' }}><Meter.Label>Seats used</Meter.Label><Meter.Value>{(formatted) => `${formatted} of 100`}</Meter.Value><Meter.Track><Meter.Indicator /></Meter.Track></Meter.Root>

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| Root gaps | `hds/sem/measure/space/100` (rows), `hds/sem/measure/space/200` (Label to Value) |
| Track color | `hds/sem/color/surface/sunken/bg` |
| Track height | `hds/sem/measure/size/{size}` |
| Track radius | `hds/sem/radius/round` |
| Indicator (fill) | `hds/sem/color/feedback/{tone}/icon` |
| Label | `hds/sem/color/content/default/fg`, `hds/sem/typography/label/*` at `md` |
| Value | `hds/sem/color/content/muted/fg`, `hds/sem/typography/caption/*` at `md` |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/meter`. Progress shares its CSS; only the fill
  color differs.
- Extension decisions: `tone` replaces the old `sentiment` and uses the library-wide
  `tone` axis. `size` takes `measure/size` steps `200`, `300`, `400` (8, 12, 16px). The
  steps `200` and `300` were added to the token set for this. The removal of `render`
  and `className` is a recorded break of the escape-hatch rule, as for Separator.
- Known constraints: the caller picks `tone`; there are no `low`, `high`, or `optimum`
  thresholds. The fill width moves with a 300ms transition, off under
  `prefers-reduced-motion`. All colors follow `data-context` and `data-section`
  overrides.
- Accessibility: `role="meter"` with `aria-valuenow`, `aria-valuemin`, and
  `aria-valuemax`. `Meter.Label` names the meter. `aria-valuetext` or
  `getAriaValueText` changes what screen readers announce. Meter is not focusable.
