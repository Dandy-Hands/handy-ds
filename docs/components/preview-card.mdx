# PreviewCard

PreviewCard shows a preview of a link's destination. The preview shows when the pointer rests
on the link or when the link gets keyboard focus. PreviewCard is one component: it wraps its
link, and `content` is the preview. The link gets the link look.

Written by <PreviewCard width="8000" content={<Profile />}><a href="#ana">Ana Ruiz</a></PreviewCard>.

## Usage

Use PreviewCard for a summary of a linked page, profile, or item. Make the link useful on its
own, because touch users do not see the preview.

Do not put content in the preview that the user needs. Do not wrap a control that is not a
link. Use Tooltip or Popover.

## Base UI API

PreviewCard wraps `@base-ui/react/preview-card`. The parts are internal. None is exported.

| Element | Notes |
| ------- | ----- |
| `Root` members (`open`, `onOpenChange`, `actionsRef`, ...) | Omitted. The preview manages itself. |
| `Trigger` | Renders the child link through `render`, with the link class. `delay` (600 ms) and `closeDelay` (300 ms) are fixed. |
| `Portal`, `Positioner`, `Popup` | Rendered inside. `side` and `align` are exposed. The side gap is fixed at `measure/space/200`. |
| Other `Positioner` members, `Arrow`, `Backdrop`, `Viewport` | Omitted. |
| `render`, `className`, `style` | Omitted. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactElement` | required | The link: an `<a href>` or a router link. One element. |
| `content` | `ReactNode` | required | The preview, such as a name and a short summary. |
| `side` | `'top' \| 'bottom' \| 'inline-start' \| 'inline-end'` | `'bottom'` | The side of the link the preview opens on. It flips when it does not fit. |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | How the preview lines up along the link. |
| `width` | `'auto' \| '6400' \| '8000' \| '9600' \| '12800'` | `'auto'` | Width of the preview. `auto`: the content sets it, up to `maxWidth`. |
| `maxWidth` | `'6400' \| '8000' \| '9600' \| '12800'` | `'9600'` | Largest width of the preview. It wins over a larger `width`. |

## Side

`side` sets the side of the link that the preview opens on. `inline-start` and `inline-end`
follow the text direction.

  <PreviewCard side="bottom" content={<Profile />}><a href="#bottom">bottom</a></PreviewCard>
  <PreviewCard side="inline-start" content={<Profile />}><a href="#inline-start">inline-start</a></PreviewCard>
  <PreviewCard side="inline-end" content={<Profile />}><a href="#inline-end">inline-end</a></PreviewCard>
</Inline>

## Align

`align` sets how the preview lines up along the link. `start` aligns the start edges.
`center` centers the preview. `end` aligns the end edges.

<Inline gap="600">
  <PreviewCard align="start" width="8000" content={<Profile />}><a href="#start">start</a></PreviewCard>
  <PreviewCard align="center" width="8000" content={<Profile />}><a href="#center">center</a></PreviewCard>
  <PreviewCard align="end" width="8000" content={<Profile />}><a href="#end">end</a></PreviewCard>
</Inline>

## Width

`width` sets the width of the preview. `auto` lets the content set it, up to `maxWidth`. The
steps read `measure/width/{step}`.

<Inline gap="600">
  <PreviewCard width="auto" content={<Profile />}><a href="#w-auto">auto</a></PreviewCard>
  <PreviewCard width="6400" content={<Profile />}><a href="#w-6400">6400</a></PreviewCard>
  <PreviewCard width="8000" content={<Profile />}><a href="#w-8000">8000</a></PreviewCard>
  <PreviewCard width="9600" content={<Profile />}><a href="#w-9600">9600</a></PreviewCard>
  <PreviewCard width="12800" maxWidth="12800" content={<Profile />}><a href="#w-12800">12800</a></PreviewCard>
</Inline>

## Max width

`maxWidth` sets the largest width of the preview. It wins over a larger `width`. Each example
has long content and `width="auto"`.

## Owner notes

- Base UI mapping: `Root`, `Trigger`, `Portal`, `Positioner`, and `Popup` from
  `@base-ui/react/preview-card`, all inside `<PreviewCard>`.
- Extension decisions: one component with a `content` prop. It shares the panel and width CSS
  with Popover. It has no title row and no X button: it closes when the pointer leaves.
- Known constraints: the preview renders at the end of the page. It uses the page colors and
  mode. The link itself follows its ancestors.
- Accessibility: the preview opens on keyboard focus and on hover. Touch users do not see it,
  so the link must work without it.
