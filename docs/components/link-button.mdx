# LinkButton

A link that looks like a Button. LinkButton renders a native `<a>` with the Action
`primary` look. Use it for navigation that must read as an action, such as "View all"
or a call to action.

<div style={row}>
  <LinkButton href="#">View all reports</LinkButton>
</div>

## Usage

Use LinkButton when the control moves the user to another page or view and must read as
an action. Do not use it for an action in place, such as submit, save, or open a dialog.
Use Button for those. Do not use Button with `href` or `render={<a />}`, because that
gives an `<a>` the wrong role. LinkButton is the only link component. For a link inside
a sentence, write a plain `<a>`. The theme styles it with the Content `link` tokens.

## Base UI API

No Base UI primitive. LinkButton uses `useRender` and `mergeProps`, so it takes the
`render` prop like a Base UI part.

| Element | Notes |
| ------- | ----- |
| `render` | Exposed. A router link can replace the `<a>`. |
| `ref` | Exposed. |
| Native link props (`href`, `target`, `rel`, `download`, `onClick`, `id`, `aria-*`, `data-*`) | Exposed as rest props. |
| `children` | Exposed. Text, an `Icon`, or both. |
| `disabled` | Removed. An `<a>` has no disabled state. |
| `className`, `style` | Removed. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `href` | `string` | — | The destination URL. |
| `size` | `'800' \| '1000' \| '1200'` | `'1000'` | Link height. `800`: dense toolbars and compact layouts. `1000`: the standard size. `1200`: large, for hero and marketing areas. The label size follows. |
| `width` | `'auto' \| 'full'` | `'auto'` | `auto`: fits the content. `full`: fills the width of its container. |
| `render` | `ReactElement \| (props, state) => ReactElement` | — | Replaces the rendered element, such as a router link. |
| `children` | `ReactNode` | — | The content: text, an `Icon`, or both. |

`href`, `render`, and `children` appear here only. They have no section below.
LinkButton has one look. It takes no `variant`.

## Size

The height axis. Each step is a `measure/size` token. Padding, gap, and label size
follow the step. A LinkButton sits flush next to a Button of the same size.

<div style={row}>
  <LinkButton href="#" size="800">Small</LinkButton>
  <LinkButton href="#" size="1000">Standard</LinkButton>
  <LinkButton href="#" size="1200">Large</LinkButton>
</div>

## Width

`auto` fits the content. `full` fills the container.

<div style={{ display: 'grid', gap: '12px', maxWidth: '320px' }}>
  <LinkButton href="#" width="auto">Auto width</LinkButton>
  <LinkButton href="#" width="full">Full width</LinkButton>
</div>

## Icons

There is no icon prop. Put an `Icon` in the children. It follows the label size and color.
An icon-only link keeps the standard padding. Give it an `aria-label`.

<div style={row}>
  <LinkButton href="#">Next step<ArrowIcon /></LinkButton>
  <LinkButton href="#" aria-label="Next step"><ArrowIcon /></LinkButton>
</div>

## Owner notes

- Base UI mapping: no Base UI primitive. LinkButton uses `useRender` and `mergeProps` from `@base-ui/react` 1.8.0.
- Extension decisions: `size` and `width` match Button and set data attributes. The look is fixed to Action `primary`, because a link needs no role. There is no `loading`, because a link navigates.
- Known constraints: LinkButton takes no `variant`, `disabled`, `className`, or `style`. Never render it as a `<button>` with `render`.
- Accessibility: native `<a>` semantics stay. The user can middle-click, open in a new tab, and copy the address. A screen reader announces a link. The focus ring comes from the base layer. An icon-only link needs an `aria-label`.
