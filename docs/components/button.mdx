# Button

Triggers an action the user takes in place: submit, save, confirm, open a dialog. A
Button is a container. Text, an icon, or both go in as children. Its colors come from
the Action category.

<div style={row}>
  <Button>Save changes</Button>
  <Button variant="secondary">Cancel</Button>
</div>

## Usage

Use a Button when the user acts in place: submitting a form, saving, opening a dialog,
or confirming a choice. Use one `primary` button per view and mark the other actions
`secondary` or `tertiary`. Do not use a Button to navigate. Use LinkButton instead.
Dialog and Menu triggers carry no Button look. Opt in with `render`:
`<Dialog.Trigger render={<Button variant="tertiary" />}>`.

## Base UI API

Wraps Base UI's `Button`. Button takes only the members below.

| Element | Notes |
| ------- | ----- |
| `disabled` | Exposed. The `data-disabled` attribute drives the disabled colors. |
| `render` | Exposed. Triggers and other parts use Button through it. |
| `ref` | Exposed. |
| Native button props (`type`, `onClick`, `form*`, `name`, `value`, `id`, `aria-*`, `data-*`) | Exposed as rest props. `type` defaults to `button`, so a plain Button never submits a form. |
| `children` | Exposed. Text, an `Icon`, or both. |
| `focusableWhenDisabled`, `nativeButton` | Removed. |
| `className`, `style` | Removed. |

## Extension API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `variant` | `'primary' \| 'secondary' \| 'tertiary' \| 'danger'` | `'primary'` | Role and weight. `primary`: the view's main action. `secondary`: supporting actions next to the main one. `tertiary`: low-weight inline actions. `danger`: destructive actions. |
| `size` | `'800' \| '1000' \| '1200'` | `'1000'` | Button height. `800`: dense toolbars and compact layouts. `1000`: the standard button. `1200`: large, for hero and marketing areas. The label size follows. |
| `width` | `'auto' \| 'full'` | `'auto'` | `auto`: fits the content. `full`: fills the width of its container. |
| `loading` | `boolean` | `false` | Shows a spinner, sets `aria-busy="true"`, and blocks clicks while the action runs. The width does not change. |
| `disabled` | `boolean` | — | Makes the button visible but inert. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Set `submit` to submit a form. |
| `onClick` | `(event: MouseEvent) => void` | — | Called when the button is activated. |
| `render` | `ReactElement \| (props, state) => ReactElement` | — | Replaces the rendered element, or lets a parent such as a dialog trigger use the button look. |
| `children` | `ReactNode` | — | The content: text, an `Icon`, or both. |

Event handlers, `type`, `render`, and `children` appear here only. They have no section below.

## Variant

The role and weight axis. It picks the `hds/sem/color/action/{variant}/*` set.
`primary` is filled. `secondary` has an outline. `tertiary` has no border or fill. `danger` is filled in the danger color.

<div style={row}>
  <Button variant="primary">Save changes</Button>
  <Button variant="secondary">Save changes</Button>
  <Button variant="tertiary">Save changes</Button>
  <Button variant="danger">Delete project</Button>
</div>

## Size

The height axis. Each step is a `measure/size` token. Padding, gap, and label size follow the step.

<div style={row}>
  <Button size="800">Small</Button>
  <Button size="1000">Standard</Button>
  <Button size="1200">Large</Button>
</div>

## Width

`auto` fits the content. `full` fills the container.

<div style={{ display: 'grid', gap: '12px', maxWidth: '320px' }}>
  <Button width="auto">Auto width</Button>
  <Button width="full">Full width</Button>
</div>

## Disabled

A disabled button keeps its size and takes no input. It reads the disabled tokens of its variant.

<div style={row}>
  <Button disabled>Save changes</Button>
  <Button variant="secondary" disabled>Save changes</Button>
  <Button variant="tertiary" disabled>Save changes</Button>
  <Button variant="danger" disabled>Delete project</Button>
</div>

## Loading

While `loading` is set, the button shows a spinner and sets `aria-busy="true"`. It is also disabled, so the disabled tokens apply. The width does not change.

<div style={row}>
  <Button loading>Saving…</Button>
  <Button loading variant="secondary">Uploading…</Button>
</div>

## Icons

There is no icon prop. Put an `Icon` in the children. It follows the label size and color.
An icon-only button keeps the standard padding. Give it an `aria-label`.

<div style={row}>
  <Button><CloseIcon />Close</Button>
  <Button variant="tertiary" aria-label="Close"><CloseIcon /></Button>
</div>

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| Background, border, text | `hds/sem/color/action/{variant}/{default,hover,active,disabled}/{bg,border,fg}` |
| Height | `hds/sem/measure/size/{size}` |
| Inline padding, gap | `hds/sem/measure/space/*` |
| Radius, border width | `hds/sem/radius/control`, `hds/sem/border/control` |
| Label type | `hds/sem/typography/label/*` |
| Focus ring | `hds/sem/color/focus/ring`, `hds/sem/border/focus` |
| Spinner | The foreground token of the current state. |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/button` 1.8.0.
- Extension decisions: `variant`, `size`, and `width` set data attributes. The CSS maps them to tokens. `loading` is new. `type="button"` is the default.
- Known constraints: Button takes no `className` or `style`. Dialog and Menu triggers do not look like a Button by default. Use `render`. The `selected` state tokens belong to Toggle and Tab, not Button.
- Accessibility: native button semantics and the focus ring come with the element. The spinner is `aria-hidden`. The loading state is announced through `aria-busy`. The spinner stops under `prefers-reduced-motion`. An icon-only button needs an `aria-label`.
