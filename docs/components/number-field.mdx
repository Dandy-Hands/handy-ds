# NumberField

A number input with decrement and increment steppers. The group renders as one
Field control: a − button, the value input, and a + button in a shared
frame.

<NumberField.Root defaultValue={5}>
  <NumberField.Group>
    <NumberField.Decrement />
    <NumberField.Input />
    <NumberField.Increment />
  </NumberField.Group>
</NumberField.Root>

## Usage

Use NumberField for a quantity the user nudges up and down — seats, copies,
minutes. Do not use it for a short known list of options; Select or Radio fits
better there. Do not use it for a range with no exact number in mind; the
library does not ship a slider yet.

## Base UI API

Wraps Base UI's `NumberField`; every part passes through unchanged, styled via
`part()`.

| Element | Notes |
| ------- | ----- |
| `Root` props (`value`, `min`, `max`, `step`, `smallStep`, `largeStep`, `snapOnStep`, `locale`, `format`, ...) | Exposed — full passthrough on the namespace. |
| `Group`, `Input`, `Decrement`, `Increment` | Styled as the Input/Field control. |
| `Decrement` / `Increment` children | Built-in minus/plus glyphs as overridable defaults. |
| `ScrubArea`, `ScrubAreaCursor`, `Clear` | Pass through unstyled. |
| Callback-form `className`/`style` | Available via passthrough, not documented. |

## Extension API

### NumberField.Root

Every Base UI prop (`value`, `min`, `max`, `step`, `onValueChange`, ...) is passthrough — it appears here only, never gets its own section.

### NumberField.Group

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `data-size` | `'800' \| '1000' \| '1200'` | `'1000'` | Control size. `800` — dense rows. `1000` — default. `1200` — large or hero forms. |
| `children` | `ReactNode` | — | Group content: decrement button, value input, increment button. |

`render` and standard attributes are passthrough on every part — they appear here only, never get their own section.

## Size

The group takes the Input/Field size axis as `data-size`. It sets height,
padding, radius, and border width from `hds/sem/measure/space/*`, `hds/sem/measure/size/*`, `hds/sem/radius/control`, `hds/sem/border/control`. The default
is `md`.

### data-size="800"

<NumberField.Root defaultValue={1}>
  <NumberField.Group data-size="800">
    <NumberField.Decrement />
    <NumberField.Input />
    <NumberField.Increment />
  </NumberField.Group>
</NumberField.Root>

### data-size="1000"

## Disabled

A disabled group keeps its footprint and takes no input.

<NumberField.Root defaultValue={4} disabled>
  <NumberField.Group data-disabled="">
    <NumberField.Decrement />
    <NumberField.Input />
    <NumberField.Increment />
  </NumberField.Group>
</NumberField.Root>

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| Group background, text, border | `hds/sem/color/field/{default,hover,error,disabled}/*` |
| Group size (height, padding, radius, border) | `hds/sem/measure/space/*`, `hds/sem/measure/size/*`, `hds/sem/radius/control`, `hds/sem/border/control` |
| Group focus ring | `hds/sem/color/focus/ring`, `hds/sem/border/focus` |
| Stepper hover | `hds/sem/color/action/tertiary/hover/{bg,fg}` |
| Value text | `hds/sem/typography/body/*` |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/number-field`. The namespace is
  mirrored, so `Root`, `ScrubArea`, `ScrubAreaCursor`, and `Clear` pass through
  unstyled; `Group`, `Input`, `Decrement`, and `Increment` are styled.
- Extension decisions: no wrapper props. The only axis is `data-size` on
  `Group`, matching `Field.Control`. `Decrement` and `Increment` ship built-in
  minus/plus glyphs as overridable `children` defaults — no `icon` prop.
- Known constraints: stepper hover borrows Action tertiary colors — the one
  deliberate cross-category read in the control look. Scrub area is unstyled;
  add classes if a surface needs scrubbing.
- Accessibility: the value is announced with its min/max context by the
  underlying behavior; the steppers are real buttons with accessible names.
  Label the field with `Field.Label` in a `Field.Root`.
