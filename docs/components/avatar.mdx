# Avatar

Shows a person's photo in a round frame. When there is no photo, or the photo fails to
load, it shows a fallback: initials or an icon. The fallback sits on a quiet neutral
ground.

<div style={{ display: 'flex', gap: '12px', alignItems: 'center' }}>
  <Avatar.Root><Avatar.Image src={photo} alt="" /><Avatar.Fallback delay={300}>RL</Avatar.Fallback></Avatar.Root>
  <Avatar.Root><Avatar.Fallback>RL</Avatar.Fallback></Avatar.Root>
  <Avatar.Root><Avatar.Fallback><PersonIcon /></Avatar.Fallback></Avatar.Root>
</div>

## Usage

Use Avatar to identify a person or an account next to a name, in lists, headers, and
comments. Always give a Fallback with initials or an icon. Do not use Avatar for
content images or logos: use `<img>`. Give the Image an empty `alt` when the person's
name shows next to it.

## Base UI API

Wraps Base UI's `Avatar`. Each part takes only the props listed below.

| Element | Notes |
| ------- | ----- |
| `Root` children | Exposed. The parts. |
| `Image`: `src`, `alt`, `srcSet`, `sizes`, `loading` | Exposed. Native `img` attributes. |
| `Image`: `keepMounted`, `onLoadingStatusChange` | Exposed. |
| `Image`: `render` | Exposed. For optimized image components such as `next/image`. |
| `Fallback`: `children`, `delay` | Exposed. |
| Image transition data attributes (`data-starting-style`, `data-ending-style`) | Kept. The CSS does not read them. |
| `className`, `style`, `ref`, other native props; `render` on Root and Fallback | Removed. |

## Extension API

### Avatar.Root

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `'800' \| '1000' \| '1200' \| '1600'` | `'1000'` | Width and height. `800`: small, for dense lists. `1000`: the standard avatar. `1200`: large, for headers. `1600`: extra large, for profile cards. The initials size follows. |
| `children` | `ReactNode` | — | The parts: `Avatar.Image` and `Avatar.Fallback`. |

### Avatar.Image

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `src` | `string` | — | The photo URL. The image shows only after it loads. |
| `alt` | `string` | — | Text for screen readers. Use `""` when the name shows next to the avatar. |
| `srcSet`, `sizes` | `string` | — | Responsive image sources, as on `<img>`. |
| `loading` | `'eager' \| 'lazy'` | `'eager'` | `eager`: load now. `lazy`: load when near the screen; also set `keepMounted`. |
| `keepMounted` | `boolean` | `false` | Loads the image in place. Set it with `loading="lazy"` or an optimized image component. |
| `onLoadingStatusChange` | `(status: 'idle' \| 'loading' \| 'loaded' \| 'error') => void` | — | Called when the load status changes. |
| `render` | `ReactElement` | — | Renders an optimized image component, such as `next/image`, in place of `<img>`. |

### Avatar.Fallback

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | — | Initials (one or two letters) or an `Icon`. Shows when there is no image or it fails. |
| `delay` | `number` | `0` | Milliseconds to wait before the fallback shows. Stops a flash while a fast image loads. |

## Fallback

The Fallback shows when there is no `src`, or when the image fails to load. With
`delay`, it waits before it shows, so a fast image does not flash the initials first.

### Image fails to load

<Avatar.Root><Avatar.Image src="data:image/png;base64,AAAA" alt="" /><Avatar.Fallback>RL</Avatar.Fallback></Avatar.Root>

### Icon

<Avatar.Root><Avatar.Fallback><PersonIcon /></Avatar.Fallback></Avatar.Root>

## Anatomy

| Part | Semantic token |
| ---- | -------------- |
| Root size | `hds/sem/measure/size/{size}` (width and height) |
| Root radius | `hds/sem/radius/round` |
| Root ground | `hds/sem/color/surface/sunken/bg` |
| Image | No tokens. Fills the Root, `object-fit: cover`. |
| Fallback color | `hds/sem/color/content/muted/fg` |
| Fallback font | `hds/sem/typography/label/*`; size `sm` at `800`, `md` at `1000`, `lg` at `1200` and `1600` |

## Owner notes

- Base UI mapping: wraps `@base-ui/react/avatar`. The Image renders only after the
  photo loads; until then, or on error, the Fallback renders.
- Extension decisions: `size` takes `measure/size` steps `800`, `1000`, `1200`, `1600`
  (32 to 64px). There is no shape prop: Avatar is always round, and a client changes
  the shape with the `radius.round` driver. There is no `tone`. The removal of
  `className`, `style`, and `ref` is a recorded break of the escape-hatch rule, as for
  Meter.
- Known constraints: the ground shows behind a transparent image. An `Icon` without
  `size` follows the Fallback font size. All colors follow `data-context` and
  `data-section` overrides. The contrast checker covers the Fallback text on its ground.
- Accessibility: Avatar is not focusable. Give `alt` text when no name shows next to
  the avatar; otherwise use `alt=""`. Fallback initials are read as text.
